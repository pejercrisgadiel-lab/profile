Academic Tracks

Computer Engineering Specializations

Discover the specialized tracks within Computer Engineering at UE Manila designed to equip you with industry-ready skills in hardware, software, networking, and intelligent systems.

Embedded Systems & IoT
Hardware-Software Integration

Focuses on microcontrollers, sensor integration, real-time operating systems (RTOS), and Smart Internet of Things (IoT) devices bridging physical objects with cloud systems.

KEY TECHNOLOGIES:
Arduino / ESP32 Raspberry Pi C / C++ MQTT & Sensors
Embedded Developer, IoT Engineer
Networks & Cybersecurity
Infrastructure & Protection

Covers computer network architecture, cloud infrastructure, routing, switching, threat management, ethical hacking, and securing enterprise IT environments.

KEY TECHNOLOGIES:
Cisco Routing Wireshark Linux Security Firewalls / VPNs
Network Admin, Security Analyst
Software Systems & Web
Full-Stack & Systems Dev

Prepares students for modern software engineering, web application development, database management systems, and building scalable enterprise software solution stacks.

KEY TECHNOLOGIES:
Python / Java JavaScript / Node SQL & Databases Git / DevOps
Software Engineer, Web Developer
Robotics & Automation
Mechatronics & Control

Combines mechanical concepts with control systems, motor controllers, computer vision, kinematics, and industrial automation to build autonomous robotic platforms.

KEY TECHNOLOGIES:
ROS / ROS2 PLC Controllers Control Systems Actuators
Robotics Specialist, Automation Engr
AI & Machine Learning
Data & Intelligent Systems

Explores data engineering, computer vision, neural networks, predictive analytics, and training machine learning models for real-world decision-making automation.

KEY TECHNOLOGIES:
TensorFlow / PyTorch OpenCV Pandas / NumPy Python
AI Engineer, Data Scientist
Hardware Architecture
Digital Logic & PCB Design

Delves into chip design, FPGA logic modeling, PCB schematic creation, processor architecture, and testing electronic hardware components.

KEY TECHNOLOGIES:
Verilog / VHDL KiCAD / Eagle FPGA Boards Assembly
Hardware Engineer, PCB Designer
